# 現場ツール箱（PWA） v0.6.0

電気工事の現場で使う計算・判定ツールを1つにまとめるアプリです。
入っているツールは次の5つです（メニューに並ぶ順）。

1. 電圧降下ケーブル選定
2. 光損失判定
3. メッセンジャーワイヤー選定（計算表「メッセンジャーワイヤー選定 ver.2」と同じ計算）
4. 宿泊先検索（現場と日付から、車で30分圏内の空室を楽天トラベルで探す）
5. 書類スキャナー（斜めから撮った書類を切り抜き・補正してA4／A3のPDFにする。端末内で処理）

## フォルダ構成

```
genba-toolbox/
├─ index.html                … メニュー画面
├─ manifest.webmanifest      … アプリ名・アイコンの設定（インストール用）
├─ sw.js                     … オフライン対応
├─ icons/                    … アプリのアイコン
├─ shared/
│   ├─ app.css               … メニュー画面のデザイン（今後の新ツールでも使える）
│   ├─ app.js                … 全ツール共通の処理（版数・オフライン登録）
│   └─ tools.js              … ツール登録表（メニューに並ぶ一覧）
├─ data/
│   ├─ voltage-drop-data.js  … 許容降下率の表・ケーブルサイズ（ここだけ直せば値が変わる）
│   └─ messenger-data.js     … ケーブル・メッセンジャーワイヤーの表と設計条件の初期値
└─ tools/
    ├─ voltage-drop/index.html … 電圧降下ケーブル選定
    ├─ fiber-loss/index.html   … 光損失判定
    ├─ messenger-wire/         … メッセンジャーワイヤー選定（index.html と calc.js）
    ├─ hotel/index.html        … 宿泊先検索
    └─ scanner/index.html      … 書類スキャナー
```

## 1. まずパソコンで確認する

`index.html` をダブルクリックすればブラウザで動きます（この方法ではオフライン機能は働きません）。
※ 宿泊先検索の空室検索だけは、GitHub Pages で公開したURLから開かないと動きません（下の「5. 宿泊先検索の準備」）。

## 2. スマホにインストールする（GitHub Pages で公開）

1. GitHub のアカウントを作り、新しいリポジトリ（例：genba-toolbox）を作る
2. このフォルダの中身をすべてアップロードする（「Add file」→「Upload files」）
3. リポジトリの「Settings」→「Pages」で、Branch を `main`、フォルダを `/ (root)` にして保存
4. 数分後に表示される `https://（ユーザー名）.github.io/genba-toolbox/` をGalaxyのChromeで開く
5. Chromeのメニュー「︙」→「アプリをインストール」（または「ホーム画面に追加」）

一度開けば、電波のない場所でも起動できます（宿泊先検索の空室検索だけは電波が必要）。
※ 公開リポジトリにすると誰でもURLを開ける状態になります。社外秘の情報は入れないでください。
※ 光損失判定の「保存」した記録や、宿泊先検索の設定（楽天のID・キー、予算、登録した現場）は、その端末・そのブラウザの中だけに残ります。スマホとパソコンの両方で使う場合は、それぞれで設定してください。

## 3. 修正したとき

1. 修正したファイルを GitHub にアップロードし直す
2. `sw.js` の `CACHE_NAME` の版数を上げる（例：v0.6.0 → v0.6.1）
3. `shared/app.js` の `version` も同じ版数にそろえる

スマホ側はアプリを開き直すと新しい版に切り替わります（反映されないときは一度閉じてもう一度開く）。

## 4. 新しいツールを追加するとき

1. `tools/` の中にフォルダを作り、`index.html` を置く（先頭の `<head>` は既存ツールを写す）
2. 画面の上部に `../../index.html` へ戻るリンクを付ける
3. `shared/tools.js` に1項目足す（`status: "ready"` でメニューから押せる、`"soon"` で準備中表示）。並び順はこの配列の順番
4. 新しいファイルを `sw.js` の `APP_FILES` に追加し、版数を上げる

## 5. 宿泊先検索の準備（最初に1回）

空室は楽天トラベルの公式API（楽天ウェブサービス）から取得します。無料ですが、自分用の「アプリID」と「アクセスキー」が必要です。

1. 楽天ウェブサービス（https://webservice.rakuten.co.jp/）に楽天IDでログインし、アプリを新規登録する
2. アプリ設定の「許可するWebサイト」に、GitHub Pages のURL（`https://（ユーザー名）.github.io/`）を登録する
   - 「IP制限」は空欄にする（スマホの回線はIPが変わるため）
3. 表示された「アプリID」と「アクセスキー（pk_で始まるもの）」を控える
4. 宿泊先検索を開き、右上の「設定」にIDとキーを入れて保存する

※ IDとキーは、このフォルダのファイルには絶対に書き込まないでください（公開リポジトリだと誰でも見られます）。必ずアプリの「設定」画面から入れます。

### 使い方

- **現場**：「USSオークション会場」（USS公式の会場案内にある20会場）から選ぶか、住所（または「緯度,経度」）を直接入力する。よく行く病院などは「設定」→「登録した現場」に追加しておくと選ぶだけで済む
- **人数**：喫煙者（自分を含む、0〜2人）と禁煙者（0〜4人）を選ぶ。1人1室で探す
- **結果の並び**：東横イン → ルートイン → HOTEL AZ → その他。同じグループ内では基準料金（初期値8,000円）以内、現場に近い順
- **予約**：東横イン・ルートイン・HOTEL AZは公式サイト、それ以外は楽天の予約ページを開く

### 検索の決まりごと

- 範囲は「車で30分」を直線距離に直した範囲（初期値で約13km）。所要時間は目安なので、結果の「現場までのルート」で確認する
- 1泊の予算上限は初期値14,000円（「設定」で変更できる）
- まず朝食付きプランだけで探し、1軒もなければ朝食なしも含めて探し直す
- ドミトリー・カプセル・ゲストハウス・民泊・共同トイレなどは除外（除外する語は「設定」で編集できる）
- 禁煙者がいるときは、禁煙室が何室まで取れるかを確認して表示する（例：「禁煙は2室まで（禁煙者2名なら宿泊可）」）
- 喫煙室は楽天APIで絞り込めないため、プラン名から判定する。喫煙者2人のときの室数は予約画面で確認する
- 空室・料金は楽天トラベルの情報。最終的な空き・料金・部屋タイプは予約画面で確認する
- 優先チェーンの順番は「設定」の優先チェーン欄で行を入れ替えると変えられる
